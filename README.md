# sadeem-site

The public website for the Sadeem app, served by GitHub Pages at
<https://sadeem-app.com>: privacy policy, terms of use, support, and the open
data Sadeem publishes under CC BY-SA 4.0.

Edit the Markdown in `src/`, run `python3 build.py`, and commit both.
